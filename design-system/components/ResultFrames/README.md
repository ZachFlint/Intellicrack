Status frames marked with the `toolResult` property, used by the Windows Sandbox configuration dialog. Every state shares the base frame: an `ic-tool-result-bg` fill, a 1px `ic-border` edge and a 4px radius. The frame starts neutral ("true") while availability is checked; "success" and "error" add a 3px left bar (`ic-result-bar`) in `ic-success` or `ic-error`, next to a status icon and a status-coloured label.
