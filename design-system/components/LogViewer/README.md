The log viewer (LogViewerWindow), a separate top-level window. A toolbar of plain text actions (Pause, Clear, Save Selected As..., Save All As..., Open Logs Folder, Reload from Disk) sits over a splitter: a filter column on the left (minimum level, logger regex, search text, case sensitivity, max rows, auto-scroll) and the record table on the right, with an accent status bar showing shown / total counts. Rows are coloured by level from ThemeManager's general colours, not the stylesheet: DEBUG text is `ic-paint-muted`, INFO `ic-paint-text`, WARNING `ic-paint-warning` on a 19% wash of itself, ERROR `ic-paint-error` on a 19% wash, and CRITICAL is a solid `ic-paint-error` badge row with black or white text, whichever contrasts better (white in both families). The colour applies to every cell of the row.
