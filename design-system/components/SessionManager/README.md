The Session Manager dialog. A splitter separates the session table (Name, Created, Modified, Messages; Refresh and Delete underneath) from the details column: a Tags group, a Session Details form and a preview, with Export, Import, Load Session and Close along the bottom. All buttons are default push buttons. Tags are removable chips (`QPushButton#tagChip`): 10px-radius pills padded 2px 8px with an `ic-border` outline on `ic-chrome` and `ic-text` text, turning `ic-accent` with `ic-on-accent` text under the pointer (second chip). Each chip leads with the app's 16px `edit_delete` icon. With no tags, an italic `ic-text-muted` line (`tag_empty_label`) reads "No tags. Add one below."
