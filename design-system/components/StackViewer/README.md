The stack viewer panel (StackViewerPanel). A toolbar row holds the source combo (x64dbg or Frida), a status label using the status quartet ("Connected" in `ic-success`, "Not connected" idle, "Source not found" in `ic-error`), and two default push buttons: Refresh and a checkable Auto that takes the checked-button look (`ic-primary-pressed` with an `ic-accent` edge) while auto-refresh is on. The frame table has zebra rows and no grid lines. Its cells are coloured per column from ThemeManager's stack palette: frame 0's index is bold `ic-stack-frame0`; return addresses `ic-stack-address`; resolved functions `ic-stack-function` and the word "unknown" `ic-stack-function-unknown`; module `ic-stack-module`; offset `ic-stack-offset`; frame and stack pointers `ic-stack-pointer`. Addresses and offsets use the 9pt code face. The footer shows the frame count and last update in the 11px `search_status_label` style. The frames shown are sample data.
