The tool-confirmation dialog (ConfirmationDialog), shown before a destructive or elevated call runs. A 14px bold header introduces the call; the `tool.function` name reads as a 16px keyword (`ic-code-keyword`) on a recessed `ic-panel-muted` strip, optionally followed by the provider ("Provided by …"). The arguments render as indented JSON in `ic-code-string` inside a Consolas field at least 150px tall, and the warning strip uses the dedicated `ic-warning-bg` / `ic-warning-text`. An "Apply this answer to" group box offers three scopes: just this call (the default), the rest of the session, or always; "always" is only enabled for tools from an MCP server, so it is shown disabled here. Deny is a solid `ic-deny` button and Approve the primary, both bold and at least 100px wide.
