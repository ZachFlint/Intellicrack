The control-flow graph view (CFGGraphView). These are the first five basic blocks of the real function at 0x140001840 in notepad.exe, the CRT startup routine its entry point tail-jumps to, found by recursive descent with capstone and laid out by the app's own CFGGraphScene (BFS layers, 60px between layers, 30px between blocks). A block is an `ic-cfg-block` card with a 1.5px `ic-cfg-block-border` and 4px radius, topped by a 22px `ic-cfg-header` strip holding its bold address in `ic-cfg-header-text`; instructions are 8pt code text in `ic-cfg-asm`, with jumps, calls and returns picked out in `ic-cfg-jump`, `ic-cfg-call` and `ic-cfg-ret`. Edges are 1.5px Bezier curves with 8px arrowheads: `ic-cfg-edge-true` for the taken branch, `ic-cfg-edge-false` for the fall-through, `ic-cfg-edge` for unconditional flow. A selected block's outline thickens to 2px in `ic-cfg-block-selected`.
