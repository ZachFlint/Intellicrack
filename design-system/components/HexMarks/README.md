Highlights painted over hex editor cells, shown on the first 256 bytes of notepad.exe. Every mark is drawn at about 47% opacity over the cell, in both the hex and ASCII columns, and a selection always wins over a mark. The mark colours come from ThemeManager's hex-mark palette and differ between the dark and light families: search hits `ic-hex-mark-search`, YARA matches `ic-hex-mark-yara`, pattern-editor fields `ic-hex-mark-pattern`, struct-template fields `ic-hex-mark-template`, the colour offered for a new bookmark `ic-hex-mark-default` or highlight rule `ic-hex-mark-rule`, and the seven `ic-hex-struct-*` colours the editor assigns when it auto-bookmarks PE and ELF structure (file header, header tables, then sections in rotation). A theme only sets the colour a new mark starts with; marks already saved keep theirs. The ten `ic-hexpat-*` colours the pattern-language evaluator cycles through are fixed in every theme. The bytes are real; which ranges are marked is illustrative, except the DOS header span (0x00 to 0x3F) and the PE header start at e_lfanew.
