The custom-painted hex editor (HexEditorWidget), showing the first 256 bytes of notepad.exe with its entropy minimap. Offsets print as `0x%08X` in `ic-hex-offset`; one-pixel `ic-hex-separator` rules split the offset, hex and ASCII columns with a 12px gap. Bytes are `ic-hex-byte`, zero bytes dim to `ic-hex-zero`, unsaved edits turn `ic-hex-modified`, and a selection fills `ic-hex-selection` with `ic-hex-cursor-text` on top (here the e_lfanew field). In the ASCII column only zero bytes take the dimmed `ic-hex-ascii-dot`; every other byte, printable or shown as a dot, draws in `ic-hex-ascii`. The 32px minimap paints one bar per 256-byte block from real entropy, interpolating `ic-entropy-low` to `-mid` to `-high`, with the viewport marked in `ic-minimap-viewport`. The content-class colour mode fills whole cells with the `ic-hex-class-*` colours. The modified state on two bytes is illustrative; the byte values are the file's.
