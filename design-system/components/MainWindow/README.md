The main window, composed from the real layout in app.py and tools.py. The menu bar carries File, View, Tools, Providers, Sandbox, Settings and Help. The toolbar runs: a secondary Load Binary button, then the Provider and Model combos, then the tool buttons (x64dbg, Cutter, Hex Editor, Ghidra, Frida, Process, Sandbox), and, pushed right, the Auto-approve and Sandbox toggles and the Cancel danger button. It is an OverflowToolBar, so at this width everything after Cutter moves behind the `»` extension button into a pop-up menu (see Buttons and MenusToolbar for those controls). Below, a horizontal splitter puts the chat panel on the left and the Analysis Output panel on the right. Analysis Output has its own header and address label, then a second splitter: closable, movable `analysis_tabs` on the left and the Functions list over Cross References on the right. The accent status bar shows the state on the left and the binary and token count on the right.
