The XPU Status dialog, which reports the Intel GPU used for local models. Four group boxes stack vertically: Device Status (status, device, driver, optimal dtype, capabilities), Memory Usage (a progress bar over a usage line), Model Cache (current usage and limit) and System Requirements, with Refresh and Close as default push buttons. The requirements box is a read-only text view whose headline is bold `ic-paint-success` ("All system requirements met.") or bold `ic-paint-warning` ("Warnings:") above a bullet list; both states are shown. Those two colours come from ThemeManager, the rest from generic styling. Values shown are sample data.
