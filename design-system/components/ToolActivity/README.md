The tool activity panel (ToolActivityPanel), which lists the tool calls running now and hides itself when there are none. Each row is a frame with the tool-result look (`ic-tool-result-bg` fill, 1px `ic-border`, 4px radius), padded 4px 8px, and holds "Running <function>", a default Cancel button, a progress bar and a wrapped progress message. The bar is indeterminate until the tool reports a fraction, then fills in `ic-accent`. Pressing Cancel disables the button and relabels it "Cancelling...". The progress message is muted 11px text; the title, Cancel button and bar use the generic label, button and progress-bar styling.
