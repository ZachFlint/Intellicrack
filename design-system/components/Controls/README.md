Thin indicators. The progress bar and slider both fill / handle in `ic-accent` on an `ic-border` track; the scroll bar is a 12px track with a rounded `ic-scrollbar-thumb` handle. The tooltip is a bordered chip on the `ic-chrome` surface. A vertical slider is the same 4px groove turned upright, its round 16px handle overhanging the groove by 6px each side; the handle moves to `ic-primary-hover` on hover, `ic-primary-pressed` while dragged and `ic-text-disabled` when the slider is disabled.
