The MCP elicitation dialog, shown when a running MCP server asks the operator for information. A 14px bold heading names the server, the server's own message follows as plain text, and a fixed caution in the warning-panel style warns never to give credentials this way. The form is built from the schema the server sent: a line edit, combo or list per field, with optional fields labelled as such in their placeholder ("optional, ...") and a required choice starting at "(choose one)". A field that fails validation says why directly underneath, and a summary line appears above the buttons. Cancel, Decline and Send are default push buttons. Per-field errors and the summary line use the `ic-error` status colour. The message, fields and buttons use generic styling. The request shown is sample data.
