Tab bar and pane. An unselected tab sits on `ic-header`; the selected tab lifts onto `ic-content` and gains a 2px `ic-accent` underline (`ic-tab-indicator`). The pane is an `ic-content` panel with a 4px radius and an `ic-border`. Closable tabs carry a close button 6px after the label, with a 3px radius that fills with `ic-hover` under the pointer (second tab). The `analysis_tabs` widget uses the same tab styling over a borderless, square `ic-content` pane.
