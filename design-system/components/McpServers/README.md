The MCP Servers dialog (McpConfigDialog). A splitter puts the server list on the left, with Add, Remove and "Import JSON..." under it, and seven detail tabs on the right: Connection, Tools, Roots, "Status and log", Resources, Prompts and "Trust and approvals". The Connection tab is a form (server id, transport, enabled, call timeout) followed by a "Local program" group (command, arguments, working directory, environment, environment file) or a "Remote endpoint" group (URL, headers, query parameters, OAuth client id, client metadata URL), then a Sandbox group. An action row offers Test connection, Start, Stop, "Set input values..." and Sign out; Save and Close sit at the bottom. The dialog names about sixty widgets and none has a dedicated stylesheet rule: everything shown is generic list, tab, group-box, field and default-button styling. Multi-line fields are plain-text editors in the code face. Values shown are sample data.
