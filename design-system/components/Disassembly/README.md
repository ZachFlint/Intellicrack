Disassembly and syntax colouring read from ThemeManager's analysis palette, not the widget stylesheet. Mnemonics are coloured by class — `ic-asm-jump`, `ic-asm-call`, `ic-asm-ret` — and operands by kind — `ic-asm-register`, `ic-asm-immediate`, `ic-asm-memory`. The same seven colours drive the code highlighter's roles (keyword = jump, function = call, string = ret, type = register, number = immediate, variable = memory). They follow the theme family, so Dark 2 paints with the Dark values. The hex editor, entropy charts and control-flow graph have palettes of their own in ThemeManager; see HexEditor, EntropyChart and ControlFlowGraph.
