The analysis text panels. `code_display` (disassembly and memory reads) is a borderless `ic-content` plain-text view in `ic-text`, whose selection is the deeper `ic-code-selection`. The Functions list (`QListWidget#function_list`) is a borderless list whose rows draw in `ic-code-function`, while a selected row keeps the `ic-selection` fill and `ic-on-selection` text. The Cross References tree (`QTreeWidget#xref_display`) is borderless with `ic-text` rows. `sandbox_output` is a 10px Consolas console in `ic-text-console`. `user_notes_text` is a code-face note field with an `ic-border-control` edge that turns `ic-accent` on focus. Panel headers are `ic-header` strips with bold titles and a muted count.
