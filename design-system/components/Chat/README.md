The AI chat panel. A `chat_header` strip on `ic-chrome` holds the title and model picker over a hairline `ic-border`. Message bubbles are role-coloured at the 8px bubble radius: `ic-bubble-user`, `ic-bubble-assistant` (raised chrome) and `ic-bubble-system` (flat grey), each with `ic-text` body text. A tool call renders its name in `ic-code-type` with monospace arguments; a tool result tints its frame with success / error colours. The composer is the `chat_input_bar` on `ic-panel-muted`, holding a rounded 8px `ic-chrome` text edit (border `ic-border-control`, `ic-accent` on focus) and the 6px-radius send button in `ic-primary`; while a response streams the send button disables to `ic-disabled-fill` with `ic-send-disabled-text` (second bar).
