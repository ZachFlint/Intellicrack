The AI chat panel. A `chat_header` strip on `ic-chrome` holds the title and the "Resources and prompts..." button (`chat_mcp_context`, an ordinary primary button) over a hairline `ic-border`. A call to a tool from an MCP server carries a `tool_source_badge` line, "via <server> (third-party)", in the 8pt code face and the `ic-warning` colour, so third-party provenance stands out. Extra result parts (`tool_result_part`) use the same face in the default text colour, and results past the display limit collapse to a "[n further result part(s) not shown]" line. Server notices appear in the `chat_notice` strip above the composer: muted 11px text on `ic-panel-muted` with a top hairline. Message bubbles are role-coloured at the 8px bubble radius: `ic-bubble-user`, `ic-bubble-assistant` (raised chrome) and `ic-bubble-system` (flat grey), each with `ic-text` body text. A tool call renders its name in `ic-code-type` with monospace arguments; a tool result tints its frame with success / error colours. The composer is the `chat_input_bar` on `ic-panel-muted`, holding a rounded 8px `ic-chrome` text edit (border `ic-border-control`, `ic-accent` on focus) and the 6px-radius send button in `ic-primary`; while a response streams the send button disables to `ic-disabled-fill` with `ic-send-disabled-text` (second bar).
