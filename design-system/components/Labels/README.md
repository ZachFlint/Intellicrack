The named label styles. Headings are 16px bold; `panel_title` and `bold_label` are bold `ic-text` at the base size. Description, secondary and muted text drop to `ic-text-muted`. `hint_label` is muted, italic and 11px (provider-dialog notices); `search_status_label` is muted at 11px (hex search and stack-viewer counts); `timestamp_label` is muted at 10px (chat times). `code_label` sets an address or value in the code face in `ic-code-variable`, and `credential_source_label` uses the same colour at 11px in the UI face.
