The MCP context browser, opened from the chat header's "Resources and prompts..." button. A server combo sits over two tabs. Resources lists what the server offers beside a read-only preview, with Read, "Insert into message" and Subscribe; Prompts lists prompt templates with an argument form, Preview and "Insert into message". A progress line under the tabs reports the last action and a Close button ends the dialog. The Roots tab of the MCP Servers dialog follows the same generic styling: two check boxes ("Offer roots to this server", "Include this session's folders"), a list of session folders, per-server folder editors with "Add folder..." and a list of what the server is offered. No widget has a dedicated stylesheet rule. Contents shown are sample data.
