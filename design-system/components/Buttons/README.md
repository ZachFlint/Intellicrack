Every push button in the app. The primary `ic-btn` is the one filled action per view (`ic-primary` → hover → pressed); Execute is the same with bold text and wider padding. Secondary, tool and toggle buttons stay transparent with an `ic-border` outline until hovered; a checked toggle fills with the primary colour. Danger is a destructive outline that fills on hover. All clear the 24px (`ic-control-h`) minimum height.
