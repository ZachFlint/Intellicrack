below. Every flagged source-string / weak-assertion test was rewritten into a
runtime gate that drives a real input through the real operation and asserts an

were also upgraded to runtime gates so the whole file is a genuine gate.

## Additional hardening (same anti-pattern, not separately listed)

- Network monitor: `test_real_tcp_listener_is_logged_with_owner_pid` opens a real
  loopback TCP listener and asserts the `listen` log line carries the exact
  `127.0.0.1:<port>`, `tcp`, and the owning PID equal to `os.getpid()` (proves
  `$ownerPid`, not the read-only `$pid`).
- Registry monitor (F-0019): `test_get_reg_value_type_reports_real_value_kinds`
  creates real DWord/String/Binary/MultiString values and runs the exact
  `Get-RegValueType` helper from the source; asserts it returns
  `["DWord","String","Binary","MultiString","Unknown"]` against the
  `PropertyType` oracle each value was created with.
- Dispatcher (F-0017): `test_dispatcher_runs_command_and_records_output_and_exit_code`
  stages the real dispatcher against a host temp dir, dispatches a real `.cmd`
  that prints a marker and exits 7, and asserts stdout == `HELLO_FROM_DISPATCHER_123`
  and result == `7`. `test_dispatcher_catch_block_logs_error` forces a real
  access-denied write failure inside the try block and asserts the catch routes a
  `dispatcher_error|...denied` line to `dispatcher_errors.log` (errors surfaced,
  not swallowed).
