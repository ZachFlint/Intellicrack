## Falsifiability note

The `SectionInfo` permission gates use the independent winnt.h `IMAGE_SCN_MEM_EXECUTE=0x20000000` / `READ=0x40000000` / `WRITE=0x80000000` constants as the oracle. The production property masks (`0x20000000`/`0x40000000`/`0x80000000`) match exactly; swapping any mask would diverge the `.text` (r-x) and `.data` (rw-) assertions. The SQLite round-trip tests load from a real on-disk DB, so a regression in byte hex-encoding, datetime encoding, JSON column handling, or enum-key coercion fails the read-back assertions.
