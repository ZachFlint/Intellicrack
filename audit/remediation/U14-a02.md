## Production fix required by a legitimate gate

`test_close_embedded_tool_tab_invokes_real_stop_tool` exposed a real bug:
`ToolOutputPanel._cleanup_bridge` (src/intellicrack/ui/tools.py) caught only
`(RuntimeError, OSError, AttributeError)`, so closing a debugger tab whose
bridge has no live connection let the bridge's `detach()` raise
`intellicrack.core.types.ToolError` ("x64dbg not running") straight out of
`_on_tab_close_requested`, crashing the tab-close path. Fix: import `ToolError`
and add it to the caught tuple (one-line behavioral fix, no functionality
removed). Also replaced a pre-existing magic-value `2` (restore_tab_state
splitter pane count) with `_SPLITTER_PANE_COUNT` to keep the touched file
ruff-clean. Verified the broader UI suite (test_app_embedded_tools,
test_overflow_toolbar) still passes (22 passed).
