## Production source change (genuinely missing functionality a real gate required)

`src/intellicrack/sandbox/windows.py` `dump_memory`: the `Add-Type` here-string
closing token `"@` was emitted as `}"@`, which is not a valid PowerShell
here-string terminator (it must begin a line). The real-PowerShell gate proved
the dispatched script never parsed and no dump was ever produced. Fixed by
emitting `}` and `"@` on separate lines. Verified: the raw production script
now parses, `MiniDumpWriteDump` succeeds, and the dump's embedded `ProcessId`
equals the target. Falsifiability confirmed by reverting the fix (test goes
red) and by corrupting the notify `source` identifier (both F-0003 gates go
red).
