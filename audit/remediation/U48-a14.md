# Remediation U48 - agent-14.md - tests/test_core/test_logging.py

All eight findings target `ColoredConsoleRenderer` tests that asserted only
substring presence (`"INFO" in result`, color code somewhere in output) instead
of the meaning/structure of the rendered line. Every flagged test now asserts
**full-string equality** against an independent oracle, `_expected_render()`,
which rebuilds the documented format
`"{ts} | {color}{LEVEL.ljust(8)}{reset} | {location} | {event}{context}"`
from documented ANSI constants - it never invokes production rendering code, so
it is a trusted external oracle, not a re-implementation captured from output.

Falsifiability: changing any color code, the 8-char padding, field order, the
reset sequence, the `module:func:line` location format, or the sorted bracketed
context segment now turns these tests red.
