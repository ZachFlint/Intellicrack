## Falsifiability

- Display/highlight tests use the separate `HexDocumentState` and an observer as
  independent oracles - a bridge that dropped, mangled, or fabricated a value would
  fail even though its own return looks healthy.
- Transform tests compare against closed-form arithmetic and stdlib codecs, never
  against the bridge's own captured output; corrupting the transform backend
  changes the bytes and reddens the assertion.
- The Google tests issue real billable calls; a rejected key, retired model, or a
  bridge that mangled the response (no `ready`, wrong usage shape, no chunks)
  propagates and fails rather than skipping.
