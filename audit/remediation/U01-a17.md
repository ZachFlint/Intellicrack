# U01-a17 Remediation - tests/test_providers/test_e2e_chat.py

All 48 audit findings on this file are FIXED. The file is a live end-to-end gate over all 7
chat providers plus cross-provider and error-handling suites. Each previously-weak assertion
was rewritten to drive a real live model call through the bridge and assert against an
implementation-independent oracle: the known answer to 2 + 2, the exact echoed Windows
notepad path, the seeded multi-turn facts (name Archimedes + binary analysis), the vendor
model-naming convention, a tight max_tokens word bound, and the HTTP client-rejection status
carried on the typed ProviderError chain.

The only constant change required to make the gates run live was updating the stale
GOOGLE_MODEL from the retired gemini-2.0-flash-lite (HTTP 404 'no longer available' on
generateContent) to the current GA gemini-2.5-flash-lite, verified to serve live
generateContent. No production src was edited.
