# U67 remediation (report agent-01.md)

Unit U67 owns four whole test files and the audit listed 5 findings against
them. Four findings map cleanly onto the owned files. The fifth
(region-filter `textChanged` wiring) was **misattributed** in the workplan to
`tests/test_audit4/c3_hex_data_inspector/test_data_inspector.py:219`, but the
test `test_region_filter_wired_to_text_changed` it describes
(`tab._region_filter.insert("ntdll")` plus the row-visibility checks) does not
exist in that file. `git grep` locates the real test at
`tests/test_audit4/b4_memory_tab/test_memory_tab.py:118`. That is where the
finding has now been FIXED into a falsifiable real gate. All five findings are
addressed; none are deleted.

| tests/test_audit4/b4_memory_tab/test_memory_tab.py:118 - test_region_filter_wired_to_text_changed (audit cited test_data_inspector.py:219; misattributed) | FIXED | Real input: a live `MemoryTab` with a real `QTableWidget` populated with two module rows (`ntdll.dll`, `kernel32.dll`). Wiring is proven two independent ways without ever calling the slot. (1) Independent oracle `QLineEdit.receivers(textChanged)` must equal `1` (a count derived from Qt's own connection table, not the slot body); deleting the production `connect` drops it to 0. (2) The field is driven only via `setText`, which emits the real `textChanged`; row visibility must flow through three values whose matching row differs each time (`"ntdll"` -> row0 visible/row1 hidden; `"kernel32"` -> flip; `""` -> all visible). A static initial state cannot satisfy all three transitions unless the signal genuinely re-drives the slot. A companion test asserts via `QSignalSpy` that `setText("ntdll")` emits `textChanged` exactly once carrying the verbatim payload `["ntdll"]`. Falsifiability verified: stubbing out the production `connect()` makes the test go red (`receiver_count 0`). |

## Fixtures / environment provisioning

- `tests/test_audit4/b4_memory_tab/test_memory_tab.py`: added type-safe
  accessor helpers (`_line_edit`, `_label`, `_table`, `_plain_text`,
  `_action_buttons`, `_region_filter`, `_region_table`, `_invoke`,
  `_call_region_filter_changed`, `_set_private`) that retrieve MemoryTab members
  via `getattr`/`setattr` with `isinstance` narrowing. This made the whole file
  basedpyright-clean (it carried 51 pre-existing `reportPrivateUsage`
  errors plus one `reportCallIssue` at HEAD; all now resolved with zero
  suppressions). The new region-filter gate uses `QSignalSpy` /
  `QObject.receivers`. No production source was edited.
- `tests/test_core/test_process_manager_audit6.py`: added module-level
  `_pid_exists` (loaded via `importlib`/`getattr` cast) and helpers
  `_obtain_confirmed_dead_pid` / hardened `_guaranteed_dead_pid` (polls the
  production probe until the OS confirms the PID dead, bounded, no bare sleeps
  as a correctness mechanism).
- `tests/test_hexcore_e2e/test_bookmarks.py`: requires the real native
  `intellicrack_hexcore` extension built via `maturin develop --release`; ships
  the `__init__.pyi` stub so both runtime and basedpyright resolve
  `HexDocument` methods. No production or config files were edited.
