## Reviewer defects fixed this attempt

1. **Order-dependent / non-deterministic SMBIOS test (was lines 1035-1051).**
   The weak `assert default_mfrs != ws_mfrs` set-inequality (plus `.get()` that
   masked a missing key as `None`) is replaced by two deterministic, exact-value
   gates that call the pure static `_anti_evasion_smbios_entries` directly with
   no mocks and no shared state:
   - `test_anti_evasion_smbios_carries_exact_profile_identity` (parametrized)
     asserts, per profile, the exact independently-known vendor identity taken
     from production's single source of truth `_anti_evasion_identity`
     (default -> `HP` / `HP EliteDesk 800 G6`, workstation -> `Dell Inc.` /
     `OptiPlex 7090`, laptop -> `Lenovo` / `ThinkPad T14 Gen 3`), the exact
     type-2 board product (`8767` / `0WN7Y6` / `21AHS00000`), the full `{1,2,3}`
     SMBIOS type set, and a non-empty serial. Keys are indexed directly so a
     missing key raises `KeyError` rather than degrading to `None`.
   - `test_anti_evasion_smbios_profiles_are_pairwise_distinct` pins the whole
     profile->vendor mapping in one assertion against fixed constants.
   Because every assertion is against a fixed expected value rather than a
   relative comparison between profiles, the result is identical on every run
   and every ordering; verified across 12 `pytest-randomly` seeds.

2. **Three forbidden `# noqa: PLC0415` suppressions (lines 101, 1262, 1321).**
   Removed all three. `QMPClient` is now imported in the module-scope
   `from intellicrack.sandbox.qemu import (...)` block and used directly in
   `set_qmp`; `yara` is imported at module scope and the two yara-fallback tests
   patch `yara.compile` directly. `ruff check` now passes with zero suppressions
   (PLC0415 no longer triggers because the imports are at module scope). The
   second yara test's weak `len(scanned_paths) > 0` was strengthened to assert
   the dropped-zip artifact (`artifact.bin`) is scanned and the user input dir
   is not.
