Source report: agent-03.md. 24 findings, all addressed by rewriting the file into
real gates. The 11 weak compiler tests and 3 weak conditional tests were merged and
strengthened into 14 compiler tests that (a) assert the exact JSON template structure
emitted by `HexPatCompiler` against known-correct reference dicts and (b) register the
compiled template into the real Rust `intellicrack_hexcore` runtime (an independent
oracle) and apply it to hand-built binary payloads, asserting exact offsets, sizes,
raw bytes and decoded values. The 6 lexer tests now assert the full ordered token
sequence with line/column positions. No test was deleted; one finding's "Remove"
recommendation was superseded by the stronger requirement to assert the full token
sequence (the EOF guarantee is folded into an exact full-sequence gate).
