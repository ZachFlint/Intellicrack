# U37-a03 Remediation — tests/test_hexcore_e2e/test_hexpat_compiler_e2e.py

## Summary

All 24 audit findings target the HexPat DSL compiler E2E suite. The flagged
tests were smoke/weak-assertion gates (return-type-only, single-key, token-count
only, exception-type-only). They are now replaced by falsifiable gates that
drive real HexPat DSL sources through the Python `HexPatCompiler` and assert the
**exact** emitted JSON/dict structure, and — wherever the construct is
materialisable — register the compiled template into the real Rust
`intellicrack_hexcore` runtime and apply it to a hand-built `struct.pack`
payload, asserting exact parsed offsets, sizes, raw bytes, and decoded display
values. The Rust runtime is an independent oracle (a different implementation
from the Python codegen), so a regression in either layer is caught.

Falsifiability was confirmed by corrupting an expected display value
(`"3735928559 (0xDEADBEEF)"`), which turned the corresponding gate RED, then
reverting. Asserted constants (full simple-struct JSON, error
message/line/column, enum/endianness decoded values) were independently
re-derived from the live implementation and matched exactly.

All 24 findings: **FIXED**. No deletions.
