## Falsifiability notes

- Start/stop: deleting the PID-tracking loop, the `%ProgramData%` default, or the
  taskkill path makes the PID file absent/at the wrong location or leaves the
  process alive -> red.
- Filter: disconnecting `textChanged`, dropping `.lower()`, inverting the
  `setHidden` predicate, or not clearing on empty -> red.
- Error callbacks: removing `on_error`, swallowing the `ToolError`, or changing
  the dialog title/text -> red.
- Retry loop: ignoring `response.success`, returning before exhausting failures,
  or removing the `asyncio.sleep(poll_interval)` -> red (count, ordering, or
  timing assertion fails).
