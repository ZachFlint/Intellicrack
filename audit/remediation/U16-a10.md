# U16-a10 Remediation - tests/test_audit3/ui/test_hxd_panel_wired.py

## Summary

The four audit findings (agent-10.md) targeted mock-the-thing-under-test
anti-patterns. Two of them (lines 92, 101) flagged fixtures that monkeypatched
the production `find_hxd_executable` detection function. The remediated file
removes all patching of the function under test: it drives the real
`find_hxd_executable` against a genuine on-disk `HxD.exe` placed on a controlled
`PATH`, and asserts exact `Path`/byte values and the resulting `MainWindow`
registration. The remaining two findings (lines 119, 465) cite QMessageBox /
QFileDialog mock fixtures that belong to `test_templates_pattern.py`; no such
fixtures exist in `test_hxd_panel_wired.py`, so they are recorded as DELETED with
that justification (the dialog-mock anti-pattern is not present in this file).
